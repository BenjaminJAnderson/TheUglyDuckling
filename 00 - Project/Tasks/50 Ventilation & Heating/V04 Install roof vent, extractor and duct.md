# V04 Install roof vent, extractor and duct

## Outcome

The shower roof vent and extractor are installed and weatherproof.

## Done when

- [ ] Roof penetration cut and sealed
- [ ] Roof vent, cowl, insect mesh and backdraught shutter fitted
- [ ] Extractor mounted
- [ ] Insulated duct run and supported
- [ ] Passive air inlet planned or fitted
- [ ] Electrical feed connected
- [ ] Roof sealed and checked for leaks

## Notes

- Avoid the solar panels and existing penetrations.
- Use a drip loop and sealed cable entry.
