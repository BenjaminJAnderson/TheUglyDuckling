# E05 Install charger, inverter, consumer unit and circuits

## Outcome

The charging, inversion and distribution equipment is installed and the circuits are first-fixed.

## Done when

- [ ] MPPT installed and solar connected through isolation and fusing
- [ ] Existing Voltanic 60 A DC-DC removed and set aside for sale or retention
- [ ] Sterling BaBy 15 A DC-DC installed in the dry location with a direct common negative
- [ ] 25 A fuses fitted at both batteries and the 60 A fuses removed
- [ ] Ignition feed fitted, fused and confirmed live only with the engine running
- [ ] BaBy temperature sensor fitted to the leisure battery negative
- [ ] Shore charger installed
- [ ] Inverter installed with its own fuse and isolation
- [ ] 230 V consumer unit and RCD/RCBO installed
- [ ] DC fuse panel installed
- [ ] DC circuits run to fridge, pump, Loopz, heater, extractors and lighting
- [ ] 230 V sockets and dedicated hob circuit run
- [ ] Circuits labelled
- [ ] Drip loops and sealed entries fitted where required
- [ ] BaBy forward charging tested with the engine running
- [ ] BaBy reverse charging tested with the leisure bank above 13.5 V

## Notes

- The inverter has its own fuse and isolation.
- Keep AC and water routes separated.
- The BaBy is not waterproof; the confirmed dry location is suitable. Keep airflow around the cooling fan.
- Use the ignition-feed mode, not voltage-sense mode, so the Pro Charge Ultra's starter output cannot trigger forward charging.
- The BaBy output and reverse-charge path connect to the battery busbar or main fuse side. If a shunt is fitted, connect to the battery side of the shunt.
- Reuse the existing heavy cable only if the lugs fit the BaBy's 6.1 mm terminals. Otherwise fit 4–6 mm² cable. Upsize for runs over about 3 m.
- Set the lithium profile and confirm 14.4 V absorption and 13.8 V float against the Eco-Worthy requirements.
- Review the one-day effort estimate; if the removal, ignition feed and testing run longer, re-baseline E05 in [[Project Plan]].
